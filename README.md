# 초원 섬 · 링커 놀이터

세모네모(SEMONEMO)의 링커들과 초원 섬에서 노는 작은 놀이터입니다. 링커들을 가슴의 문양(○ △ □)대로 섬에 나눠 주는 단계 놀이(나누기)도 있습니다.

**플레이:** https://seongyooo.github.io/linker-meadow/

## 조작

| | 마우스 | 터치 |
|---|---|---|
| 링커 잡기·옮기기 | 왼쪽 버튼을 누른 채 끌기 | 링커를 손가락으로 끌기 |
| 던지기 | 끌다가 휙 놓기 | 끌다가 휙 놓기 |
| 시점 돌리기 | 오른쪽 버튼을 누른 채 끌기 | 빈 곳을 끌기, 두 손가락으로 비틀기 |
| 시점 옮기기 | Shift + 오른쪽 끌기, 가운데 버튼 끌기 | 두 손가락으로 끌기 |
| 확대·축소 | 휠 | 두 손가락 벌리기·모으기 |

## 놀이터

처음 열리는 화면이 놀이터입니다. 링커 한 명과 함께 시작해, 아래 도구 칸에서 도구를 끌어다 초원에 놓을 수 있습니다. 누르기만 하면 섬 어딘가에 떨어집니다.

- **링커**: 친구를 더합니다(16명까지).
- **나비**: 링커들이 쫓아다니고, 가끔 머리에 내려앉습니다.
- **모자**: 가까운 링커가 주워 씁니다.
- **공**: 링커들이 차며 놉니다.
- **우산**: 링커가 들고 다닙니다.
- **비구름**: 비가 내린 자리에 꽃이 피고, 링커들은 비를 피해 우산 밑으로 모입니다.
- **미끄럼틀·그네·시소**: 링커들이 타러 옵니다.

놓은 도구는 시간이 지나면 사라집니다. 바람에 날아가거나 섬 밖으로 굴러떨어져서 더 일찍 사라지기도 합니다.

## 나누기

왼쪽 위의 **나누기**를 누르면 링커들을 가슴의 문양과 같은 섬으로 옮기는 단계 놀이가 열립니다. 주소 끝에 `?level=2`처럼 붙여서 단계를 바로 열 수도 있습니다(1~5).

## 만든 방법

- 섬, 풀, 꽃, 덩굴, 링커는 세모네모(Unity)의 모델과 셰이더를 [three.js](https://threejs.org)로 옮긴 것입니다.
- 빌드 없이 그대로 쓰는 정적 페이지입니다. three.js는 jsDelivr에서 불러옵니다.
